# Contributing

Thank you for your interest in From Connectome to Control.

This repository is currently in the research-design stage. Contributions should improve scientific clarity, reproducibility, software quality or accessibility.

## Before contributing

- Read README.md, RESEARCH_PROTOCOL.md and METHODOLOGY.md.
- Check the open issues and current roadmap.
- Discuss major changes to the research question or circuit scope before implementing them.

## Contribution principles

- Keep scientific claims traceable to primary sources.
- Separate source observations from model assumptions and simulation outputs.
- Preserve data provenance and licensing requirements.
- Add tests for reusable code and data transformations.
- Record software versions and random seeds for experiments.
- Do not commit restricted or large raw datasets.
- Do not present simulated outcomes as biological observations.

## Documentation style

Technical explanations should be precise enough for researchers to reproduce the work. Where useful, follow them with a clearly labelled layperson summary that explains the same idea without changing its scientific meaning.

## Reporting issues

Include the relevant configuration, software versions, error messages and a minimal reproducible example. Do not upload private credentials or restricted data.

**Layperson summary:** Contributions are welcome when they make the project more scientifically reliable, easier to reproduce or easier to understand.
